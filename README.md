# CivicAssist

CivicAssist is a smart civic assistance platform that helps users navigate government and public service portals easily. The application guides users to the correct complaint or service portal based on their issue and simplifies the process of accessing civic services online.

### Features

* Helps users find the correct civic service portal
* AI-powered guidance and assistance
* Simplifies navigation through government websites
* User-friendly and organized interface

### Built With

* React.js for the frontend interface
* FastAPI for backend APIs and services
* MongoDB for database management
* OpenAI API for AI-powered assistance
